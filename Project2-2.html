Overview

The second dataset I chose for Project 2 is Ellie’s countries by electricity production from Wikipedia. The data is arranged with each country as a row and columns representing different types of electricity generation. Although the dataset is presented in a table, it is not tidy because some of the columns have multi-level headers. For example, coal and gas are grouped under fossil fuels. These categories and the individual generation methods should be represented as variables. I will retain the country and determine how the grouped categories and individual generation methods can be represented in a tidy format. I will probably use pivot_longer() and other dplyr functions to reorganize the columns. For the analysis, I could explore differences in electricity generation between countries. A couple of questions are which countries have the most renewable electricity production and the lowest fossil-fuel production.

Transform the dataset from wide to long format using pivot_longer(), placing each electricity generation method in its own row. It removes the _twh suffix from method names, groups the methods into fossil fuels, nuclear, and renewables, and keeps the country, generation type, method, production amount, and reporting year for analysis.

electricity_prod_long <- electricity_prod |>
  pivot_longer(
    cols = c(
      coal_twh, gas_twh, other_fossil_twh,
      nuclear_twh, hydro_twh, wind_twh, solar_twh,
      bioenergy_twh, other_renewables_twh
    ),
    names_to = "generation_method",
    values_to = "electricity_twh"
  ) |>
  filter(!is.na(country)) |>
  mutate(
    generation_method = sub("_twh$", "", generation_method),
    generation_type = case_when(
      generation_method %in% c("coal", "gas", "other_fossil") ~ "Fossil fuels",
      generation_method == "nuclear" ~ "Nuclear",
      TRUE ~ "Renewables"
    )
  ) |>
  select(country, generation_type, generation_method, electricity_twh, year)

Summarize electricity production by country, reporting year, and generation type, calculating the total terawatt-hours (TWh) for each category. Transform the data back to wide format, with separate columns for fossil fuels, nuclear, and renewables. This makes it easier to compare production across generation types and identify countries with the highest renewable electricity production.

country_summary <- electricity_prod_long |>
  group_by(country, year, generation_type) |>
  summarise(
    total_twh = sum(electricity_twh, na.rm = TRUE),
    .groups = "drop"
  ) |>
  pivot_wider(
    names_from = generation_type,
    values_from = total_twh
  )

Conclusion

The dataset was transformed from wide to long format using pivot_longer(). The country names, electricity generation methods, production values, and reporting years were organized into separate variables, making the data easier to analyze. The analysis summarized electricity production by country and generation type, then identified the ten countries with the highest renewable electricity production. A bar chart was created to compare renewable electricity production across these countries. One limitation is that the reporting year varies by country, so the comparisons do not represent exactly the same year for every country. For future analysis, the dataset could be used to compare the percentage of electricity generated from renewable and fossil-fuel sources in each country.
